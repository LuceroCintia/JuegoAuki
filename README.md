# JuegoAuki

Versión inicial de **Aventuras Blocky: La Isla del Saber**, una app de escritorio en **C# + Avalonia** pensada para niños de 8 años.

## Qué incluye
- Personalización básica del avatar.
- Tres mundos educativos: matemáticas, lectura y lógica.
- Sistema de recompensas con monedas, estrellas y nivel.
- Misiones rápidas con feedback positivo.

## Estructura
- `JuegoAuki.Desktop/`: proyecto principal de escritorio.

## Ejecutar localmente
Necesitas el SDK de .NET 8 instalado.

```bash
dotnet restore JuegoAuki.Desktop/JuegoAuki.Desktop.csproj
dotnet run --project JuegoAuki.Desktop/JuegoAuki.Desktop.csproj
```

## Nota
En este entorno no hay SDK de .NET disponible, así que el proyecto quedó preparado pero no pudo compilarse aquí.
